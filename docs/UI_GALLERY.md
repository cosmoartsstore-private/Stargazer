# UI Gallery

更新日: 2026-07-31

Stargazerの公開用画面サンプルです。全画面をデフォルトテーマとチェックテーマの同一条件で収録しています。

- 画面サイズ: 1920×1080
- 表示データ: 公開用の固定サンプルデータ
- デフォルトテーマ: 標準のダーク配色
- チェックテーマ: 標準のスカイブルー配色
- ヘルプ内の画面プレビュー: 製品仕様に従い、外側のテーマにかかわらずデフォルトテーマで表示

各画像を選択すると、原寸で確認できます。
