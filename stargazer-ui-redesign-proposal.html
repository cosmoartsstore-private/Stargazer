Stargazer UI proposal

操作画面の密度を保ったまま、状態と操作の見分けをそろえる

読み込み中、抽選、出席、NG管理、キャスト名簿、イベント一覧、左タブを同じ視覚規則で再整理する案です。既存の暗色基調とアクセント色は維持し、縦線で選択状態を示す表現を廃止します。

状態はピル
操作は四角ボタン
一覧は行選択
縦線装飾なし

実装時の分割

このHTML案を実装へ移す場合の主要な変更単位です。

LoadingOverlay

強い暗幕から、上部進行バー + スケルトン表示へ変更する。

Import mapping

通常取り込みと「抽選だけ行う」を分岐し、同じ列マッピングを使えるようにする。

LotteryPage

当日枠、合計当選者数、合計席数を分けて表示し、結果一覧は内部スクロールにする。

AttendancePage

出席中/待機のBOX内は1名1行。保存モーダルは上段2項目、下段キャスト一覧。

NGUserManagement

件数バッジ、詳細ボタン、要注意候補を共通ボタン形へ寄せる。

Cast/Event list

選択時の縦線を廃止し、背景と輪郭のみで現在位置を表す。

Delete action

削除は文字ボタンではなく、赤背景の × ボタンへ統一する。

Shared tabs

下線タブをピル型セグメントへ寄せ、ページ間の視覚差を減らす。
